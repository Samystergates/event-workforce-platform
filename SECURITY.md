# Security Policy

## Scope

This repository is a software portfolio project. Do not use it to process real customer data or deploy it to production without an independent security and operational review.

## Reporting a vulnerability

Please do not publish vulnerability details in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use the repository's **Security → Report a vulnerability** workflow. Otherwise, contact the repository owner privately through GitHub and request a secure reporting channel.

Do not include real credentials, personal data, or customer data in a report.

## Credential exposure

If a credential is found in the repository or its history, assume it is compromised. Revoke or rotate it with the relevant provider; deleting the file or changing Git history alone does not invalidate a credential.
